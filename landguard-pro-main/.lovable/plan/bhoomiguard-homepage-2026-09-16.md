# BHOOMIGUARD Homepage

## Scope
Build only the responsive homepage shown in the reference image. No dashboards, extra sections, statistics, or marketing content will be added.

## Implementation
- Create a full-screen rural farmland scene with a drone survey and digital land-boundary overlay.
- Reproduce the top BHOOMIGUARD navigation, left-aligned headline and action buttons, and right-side white login panel.
- Make the login fields, password visibility, remember-me option, and buttons functional without creating dashboard destinations.
- Match the reference's dark-green government-tech palette, curved lower foreground, spacing, and responsive mobile stacking.
- Add homepage-specific page title and social metadata.

## Technical details
- React and TypeScript with Tailwind CSS v4 semantic design tokens.
- Lucide React icons for navigation, fields, and actions.
- Generated farmland artwork stored as a project asset; the uploaded screenshot remains a visual reference only.
- Validate the finished page in desktop and mobile layouts.
